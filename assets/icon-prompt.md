# Иконка Project Hub 1.0.7

Сгенерировано встроенным image_gen (imagegen), без API-ключа пользователя. Исходник: project-hub-v2.png, macOS-ресурс: project-hub-v2.icns. Прежняя иконка сохранена. В приложение и боковое меню включён новый знак. sips и iconutil создают стандартные размеры для macOS.

Финальный запрос:

> Use case: logo-brand. Asset type: final macOS application icon for Project Hub, personal client and task workspace. Create a refined monochrome macOS icon: a large softly rounded graphite-black square tile, subtle satin depth and soft beveled edge, centered sculptural ivory-white symbol of three neatly stacked rounded cards connected by a single understated hub notch, recognizable at 32px. Calm, premium, minimal, Apple-like quality without copying any existing logo. Front view, symmetrical optical balance, no perspective. Tile fills 90% of square canvas with transparent corners outside tile, no surrounding mockup, no text, no letters, no watermark, no decorative clutter. 1024x1024.

Результат с прозрачностью; инструмент вернул 1254 × 1254. Размеры для .icns получены из него штатными утилитами macOS.

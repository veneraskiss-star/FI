# Состояние проекта

## Реализовано: этап 1

- React/TypeScript/Vite, Tailwind, Lucide, Radix Dialog, кнопка по шаблону shadcn/ui.
- Светлая и тёмная темы; адаптация к ноутбуку и небольшому экрану.
- Главная: счётчики, требует внимания, поиск, фильтры и список клиентов.
- Клиенты: добавление, редактирование всех полей, архив и восстановление.
- Карточка: обзор, план и задачи, хронологическая история.
- Задачи: создание, редактирование, удаление, статусы в таблице, сроки и ответственный, фильтры, просрочка.
- История: создание, редактирование, удаление, дата и тип. Последняя активность вычисляется автоматически.
- Глобальное добавление с выбранным клиентом.
- SQLite: четыре сущности, внешние ключи, журнал изменений и дата завершения задач, постоянное локальное хранение.
- Только loopback, проверка Origin для API, обработка ошибок, документация.

## Не реализовано: этап 2 (нужно согласование)

Отчёты за период, копирование сводки, ExcelJS, интерфейс резервного копирования/восстановления. Раздел «Отчёт» явно объясняет статус разработки. Ручное сохранение остановленной базы описано в README.

## Известные ограничения

Один локальный пользователь. Нет авторизации. Начальная база пустая. Для архива редактирование задач и истории отключено до восстановления клиента. Ближайшие задачи — незавершённые задачи со сроком до трёх месяцев вперёд, включая просроченные. API рассчитан на небольшую персональную базу.

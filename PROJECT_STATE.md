# Состояние проекта

Обновлено 16 октября 2026.

## Реализовано и проверено

- Первый этап: главная, фильтры и поиск, клиент с тремя вкладками, задачи, история, архив/восстановление, глобальное добавление.
- SQLite: Client, Task, Activity, ChangeLog; связи, даты выполнения и изменений, данные между запусками.
- Чёрно-белое оформление по последнему пожеланию пользователя: тонкие разделители, чёрные действия, монохромные состояния, светлая и тёмная темы.
- Electron-оболочка: .app для Mac Apple Silicon, отдельный runtime, запуск без Терминала/Node.js, полный выход останавливает сервер. Только 127.0.0.1, случайный порт, HttpOnly cookie, проверки Host/Origin. Renderer без Node, изолированный sandbox/preload, ограниченные IPC.
- База Mac-приложения в userData, отдельно от приложения. Первый перенос старой базы через SQLite Backup с сохранением WAL; существующая база не перезаписывается.
- Экран подключения ChatGPT: официальный OAuth (state, nonce, PKCE, проверка JWT по JWKS, issuer/audience/exp/sub), обновление токенов, несколько регистраций, выбор и отключение. Учётные данные зашифрованы safeStorage, недоступны renderer и SQLite.
- Разбор встречи: текст/.txt, дата и каталог моделей аккаунта, предварительный контекст, явная отправка, потоковый Responses store:false, предложения с дословными цитатами, редактирование и выбор, предупреждение о точных дубликатах. Сохранение выбранного одной транзакцией, защита от повторного запроса и устаревшего контекста.

## Проверки

- npm run build:desktop: TypeScript, Vite и сборка Electron прошли.
- npm test: 7 проверок прошли. Включены API и сохранение после перезапуска, журнал, архив, неправильные даты, Origin, атомарное применение встречи/повтор/конфликт, источники/дубликаты, обрыв/разделение SSE, перенос WAL без перезаписи базы.
- Исходная и упакованная Electron-версии успешно запустились на временных базах и завершились автоматически.
- Снимок метрик упакованной версии при старте: суммарно около 355 МБ working set по четырём процессам, CPU в момент снимка 0%. Это единичный замер, не длительный нагрузочный тест.
- Браузерная проверка на отдельной временной базе: главная, создание вымышленного клиента, карточка и окно разбора. Чёрно-белый интерфейс осмотрен.

## Что не подтверждено

Реальный OAuth и анализ через личный ChatGPT не выполнялись: вход и разрешения должен завершить пользователь. Доступность плана, список моделей и реальные ответы проверяются после подключения. Автоматические тесты не расходуют лимиты и не используют пользовательские токены. Полный визуальный сценарий просмотра предложений с живым ответом модели ещё предстоит проверить.

## Ограничения

Локальная сборка .app не подписана Developer ID и не нотарифицирована Apple. Сборка сейчас для arm64. Нет аудиораспознавания: загружается готовый текст. Только точное нормализованное совпадение названий задач даёт локальное предупреждение о дубликате; близкие по смыслу задачи нужно проверять вручную. Любые предложения ИИ нуждаются в проверке пользователем.

Mac-приложение и браузерный запуск после первого переноса используют разные базы; синхронизации нет. Настройки ChatGPT на другом Mac требуют повторного входа. См. README.md и REQUIREMENTS_UPDATE.md.

## Не реализовано: исходный этап 2

Отчёты, копирование сводки, ExcelJS, интерфейс резервного копирования/восстановления. Согласование на этот этап не получено. Ручной перенос и копирование остановленной базы описаны в README.

## Следующие действия

Пользователь оценивает монохромный дизайн, выполняет подключение ChatGPT и проверяет разбор на несекретной тестовой расшифровке. При ошибках сохранить только обезличенное описание, без токенов и URL OAuth. Развивать существующий проект, не пересоздавая базу.

Финальная .app открыта обычным способом через macOS и показывает главную. Проверено, что API доступен своему окну через защищённую cookie. Снимки интерфейса сохранены в assets/preview-monochrome.jpg и assets/preview-desktop.png. Файл приложения: release/Project Hub-darwin-arm64/Project Hub.app.

## Исправление 1.0.1 — отказ анализа

Пользователь сообщил об общем сообщении «OpenAI отклонил анализ». Обнаружен дефект формата запроса: input был строкой, хотя Sign in with ChatGPT требует массив сообщений. Исправлено на [{role:'user',content:...}]. Точный ответ первоначального отказа не сохранялся, поэтому эта причина вероятная, а не подтверждённая серверным кодом.

Добавлена безопасная диагностика HTTP/потоковых ошибок: статус, код, поле и request ID; произвольный текст OpenAI не показывается, чтобы не раскрыть расшифровку или учётные данные. Различаются лимиты, ограничения плана, недоступная модель, временные сбои. Проверено 11 тестов, TypeScript/Vite/Electron-сборка прошла. Реальный анализ после исправления пока не проверен. Новая .app в release/1.0.1/Project Hub-darwin-arm64/Project Hub.app; старое окно не закрывается автоматически, чтобы сохранить несохранённый текст.

Источник требований формата: https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations

## Версия 1.0.2 — разбор сводок и общие варианты

По уточнению пользователя разбор расширен на любую выбранную информацию о клиенте. Несколько событий со своими датами и типами, задачи со статусами, предложения по stage/type/analyst/health/state/risks. В review у каждого события дата; неизвестные даты пустые и не подменяют последнюю активность. Варианты stage/type/analyst — dropdown из каталога пользователя. Этап также меняется dropdown прямо в карточке.

Общие для всех клиентов списки (подтверждено пользователем): stages/types/analysts/owners/activityTypes. Редактор «Варианты полей» доступен в боковом меню, формах и разборе. Каталог хранится атомарно в sidecar `<DB_PATH>.options.json`; существующие свободные значения импортируются без изменения записей. Удаление используемого варианта запрещено. База остаётся из четырёх таблиц. Перенос в .app сохраняет и sidecar каталога.

Контекст анализа включает поля, пользовательские списки, существующую историю и задачи; он раскрывается перед отправкой. Проверка версии защищает от применения после изменения каталога или истории. Только выбранные предложения сохраняются атомарно. Модель не создаёт варианты автоматически. Неизвестное значение dropdown требует ручного выбора.

Проверки: 15 тестов прошли, TypeScript/Vite/Electron сборка прошла. В браузере на отдельной базе проверены настройка этапов/ответственных, создание клиента с этими вариантами, смена этапа прямо в карточке и ввод накопленной сводки. Проверка реального ответа ChatGPT после этих изменений ещё не выполнена. Упакованная .app: release/1.0.2/Project Hub-darwin-arm64/Project Hub.app. Старые версии не закрываются и не перезаписываются автоматически.

Ограничения: семантические дубликаты пользователь проверяет вручную. Дата completedAt импортированной выполненной задачи — время импорта, историческая дата хранится отдельным событием. Состояния здоровья клиента и статусы задач фиксированы по смыслу; их переименование/расширение не входит в текущую доработку.

Готовая .app 1.0.2 успешно запустилась на временной базе, создала SQLite и каталог и завершилась. Дополнительно в браузере проверено открытие настройки вариантов прямо из разбора и возврат без потери введённого тестового текста. Снимок редактора: assets/preview-catalog.jpg.

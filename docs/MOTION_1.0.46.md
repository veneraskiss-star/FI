# FI 1.0.46 — микровзаимодействия

## Аудит и реализация

- Найдены два определения появления workspace (style.css/design-system.css), независимый мгновенный active:before, разрозненные длительности и отсутствие layout-переходов фильтров/строк. Motion теперь единственный владелец движения workspace и адаптированных диалогов; старые правила отключены для этих поверхностей.
- Централизованы быстрый отклик 140ms, UI 220ms, поверхность 300ms, вход страницы 180ms и выход 70ms; easing [.2,.75,.25,1], spring stiffness 430/damping 38/mass .8 без выраженного отскока.
- Сначала внедрены/проверены sidebar shared-layout indicator, hover иконок и переходы страниц. Затем добавлены фильтры, строки и диалоги.
- Sidebar: тот же индикатор 3×16px, те же цвета/позиции; меняется способ перемещения. Страница смещается только на 3px, выходящая inert; нет длительной блокировки навигации.
- Lucide остаётся основной системой. Сохранены контекстные размеры и оптическая поправка календаря; общий stroke 1.7, исключения пустых состояний сохранены. Иконки настроек, плюса, стрелок и почты реагируют только на hover. Lucide Animated изучен, дополнительные пакеты/скопированные компоненты не добавлены.
- Таблицы сохраняют native table/tr/td. Layout анимирует только позицию строк; цвета hover и существующих выбранных фильтров сохранены. Микроотклик стрелки/нажатия без превращения строк в карточки.
- Radix продолжает управлять доступностью/фокусом/Escape. Общая обёртка добавляет AnimatePresence/opacity/y, отключает конкурирующий CSS, сохраняет обработчики и возвращает фокус на исходную кнопку. Условные формы также удерживаются до конца выхода.
- Нет новых API, миграций, внешней сети или изменений бизнес-логики. Геометрия, палитра, шрифты и компоновка сохранены; отдельные размеры иконок не заменялись одним универсальным размером.

## Проверки

UI — только вымышленные данные на отдельных БД. Никаких реальных писем, приглашений или запросов ИИ.

- Переходы главная → сотрудники → ссылки, главная → клиенты; положение/фокус навигации и отсутствие дублирующихся страниц после завершения.
- Фильтр клиентов: 8 → 3 записи с рисками, возврат всех; таблица сохраняет колонки и интерактивность.
- Форма клиента: открытие, Shift+Tab замыкается на последней кнопке, Escape закрывает, фокус возвращается на «Клиент».
- Профиль с autofocus поля: Escape возвращает фокус на «Изменить профиль»; данные не сохранялись.
- Условный ассистент: открытие/закрытие Escape, фокус возвращается на «Ассистент»; реальные запросы не запускались.
- Отдельная тестовая сборка с MotionProvider reducedMotion="always": движение отключено, computed transform страницы none, фильтры и окно клиента работают, Escape/возврат фокуса сохраняются. Системные настройки macOS не менялись. CSS media-query проверен по исходнику; физическое переключение системного reduced motion не выполнялось.
- Короткий RAF/Long Tasks замер в тестовом browser renderer на 8 клиентах: p95 интервала около 9ms, 0 long tasks >50ms; после завершения перехода active animations 0. Это локальная выборка, не универсальный FPS-бенчмарк и не длительное профилирование Electron.
- Основной JS gzip вырос примерно со 151 до 200 КБ из-за Motion. Ленивый chunk редактора заметок сохранён. Vite предупреждает о chunk >500КБ; новых графических/анимационных библиотек кроме Motion нет.

Непроверено: полный VoiceOver-аудит, все комбинации вложенных окон/данных, длительная нагрузка на слабом Mac. Нативная notch-анимация не изменялась. Реальные подключения и секреты не трогались.

Сборка npm run build/build:desktop успешна; npm test — 92/92. Пакет release/1.0.46/FI-darwin-arm64/FI.app прошёл изолированный Electron smoke (HUB_SMOKE_READY, SQLite доступна).

Документация: [Motion](https://motion.dev/docs/react), [AnimatePresence](https://motion.dev/docs/react-animate-presence), [layout](https://motion.dev/docs/react-layout-animations), [Lucide Animated](https://lucide-animated.com/).

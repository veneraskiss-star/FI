## Реальная UI-проверка

Только отдельные тестовые базы с вымышленными данными; сеть Яндекса/ИИ и отправка почты в фиктивных экранах отключены.

- Главная: заполненный список, статистика, внимание и действия.
- Карточка клиента: обзор, план/задачи, история, пустые контакты; форма редактирования.
- Сотрудники: список, создание и раскрытие необязательных полей.
- Ссылки: пустой список, создание и группы (структура проверена по исходнику).
- Отчёты: клиенты/период, пустой результат, состояние без подключения; генерация не запускалась.
- Настройки: рабочие настройки, обе темы, каталог полей.
- Заметки: список, редактор и GFM-предпросмотр, вложенные пункты и чекбоксы, нижние действия.
- Календарь: подключённая сетка и событие с участником, форма создания проверена по коду; реальное событие не создавалось.
- Почта: подключённый список, открытое письмо, форма черновика. Отправка не запускалась.
- Ассистент: начальный орб, поле ввода, параметры. Фиктивный ответ; настоящего ИИ-запроса нет.
- Подключения ChatGPT/Яндекс, сравнение предложений, профиль и media corner проверены по компонентам и общим правилам; реальные пароли/фото/музыка не менялись.

## Границы проверки

FI — Mac-приложение с minWidth 900/minHeight 640. Полноценного мобильного продукта нет. Узкие layout-правила проверены по коду; отдельная физическая матрица экранов/браузеров, VoiceOver, reduced-motion в настройках ОС и frame-time профилирование не выполнялись. Нативная notch-анимация уведомлений не изменялась, чтобы не регрессировать ранее откалиброванную геометрию. Не заявляется исчерпывающая проверка всех сочетаний ошибок и данных. Реальные отправки SMTP, приглашения, OAuth и AI не запускались.

## Поддержка системы

Общие изменения вносить в src/design-system.css. Специфические правила редактора, орба, плеера и notch сохранять в их компонентах. Не добавлять сеть/миграции ради визуального оформления. Токены предназначены для постепенной унификации; полное удаление старого CSS потребует отдельной миграции и не выполнено автоматически.

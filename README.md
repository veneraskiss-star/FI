# Project Hub

Персональное приложение для работы с клиентами, задачами и историей встреч. Русский интерфейс, чёрно-белое оформление, светлая и тёмная темы. SQLite на компьютере пользователя. Основная работа доступна без интернета и аккаунта ChatGPT.

## Запуск на Mac без Терминала

Готовая сборка для Mac с Apple Silicon находится в `release/1.0.4/Project Hub-darwin-arm64/Project Hub.app`.

1. Откройте эту папку в Finder.
2. Дважды щёлкните **Project Hub**. При желании перенесите приложение в «Программы» и добавьте в Dock.
3. Для полного выхода нажмите **⌘Q**. Внутренний локальный сервер завершится вместе с приложением.

Устанавливать Node.js и вводить команды для использования готовой сборки не нужно. Это локальная сборка без Developer ID и нотарификации Apple. Для распространения другим пользователям потребуется подпись/нотарификация; защиты macOS приложение не отключает.

## Данные

Mac-приложение хранит базу отдельно от своего пакета: `~/Library/Application Support/Project Hub/project-hub.sqlite`. Кнопка «Открыть папку локальных данных» находится в окне подключения ChatGPT.

При первом запуске, если база приложения ещё не существует, существующая база из исходного проекта копируется через SQLite Backup. Исходная база остаётся на месте. Существующая база Mac-приложения не перезаписывается. После этого браузерный запуск из исходников и Mac-приложение имеют отдельные базы: изменения между ними не синхронизируются.

Обновление приложения не удаляет данные. Не удаляйте папку локальных данных. Пользовательская база исключена из Git и пакета приложения.

Для ручной резервной копии завершите приложение через ⌘Q и сохраните папку данных целиком. Для восстановления сначала сохраните текущую папку отдельно, затем замените её нужной копией при закрытом приложении. На другом Mac перенесите приложение и папку данных. Зашифрованные подключения ChatGPT привязаны к системному хранилищу исходного Mac — на другом компьютере войдите повторно. Интерфейс резервного копирования относится к исходному этапу 2 и пока не реализован.

## Варианты полей

Слева внизу откройте **Варианты полей**. Задайте свои общие для всех клиентов списки: этапы, типы клиентов, аналитики, ответственные за задачи, типы записей истории. Каждый вариант указывается с новой строки. Первоначальные значения можно заменить, пока они не используются в записях. Используемые варианты нельзя удалить до замены в данных.

Все поля карточки, включая этап, изменяются через «Изменить клиента»; обзор предназначен для чтения. В форме клиента и задач аналитик, тип, этап и ответственный выбираются из этих же списков. Настройку можно открыть и из формы, и при разборе информации.

Списки хранятся локально рядом с базой: `project-hub.sqlite.options.json`. При обновлении уже записанные свободным текстом этапы, типы и имена сохраняются и попадают в первоначальный каталог. Новых таблиц в SQLite не добавляется. Для переноса/копирования сохраняйте всю папку данных, включая этот файл.

Статусы задач и состояния «По плану / Есть риски / Проблемы» остаются фиксированными: от их значения зависит главная сводка.

## Разбор информации через свой ChatGPT

1. В Mac-приложении откройте **Подключение ChatGPT** → **Продолжить с ChatGPT** и завершите официальный вход в браузере.
2. В карточке клиента нажмите **Добавить информацию с ChatGPT**.
3. Вставьте накопленную сводку, историю проекта, заметки, переписку или расшифровку; можно загрузить `.txt`.
4. Модель выбирается автоматически из доступных. При необходимости раскройте «Модель и дата текста»: поле «Когда был написан текст?» нужно только для слов «завтра»/«через неделю» и может оставаться пустым. При неизвестной дате такие сроки не вычисляются.
5. Откройте раздел **Что будет отправлено вместе с текстом**, затем нажмите **Получить предложения**.
6. Проверьте события по отдельности, их даты, задачи и предлагаемые поля карточки. Выберите нужное, отредактируйте и сохраните.

Из одной сводки можно получить несколько событий с разными датами. Неизвестная дата остаётся пустой; запись будет показана в истории как «Дата не указана». Такая запись не подменяет последнюю датированную активность. Даты, ответственные и факты не должны выдумываться — результат необходимо проверить.

Предложения по этапу, типу и аналитику используют ваши списки. Значения выбираются в выпадающих списках на экране проверки; можно сразу открыть настройку вариантов. Если модель предложила неизвестный вариант, он не выбирается автоматически и требует вашего выбора. Для каждого предложения показывается дословный фрагмент исходного текста.

Существующая история, задачи, текущие поля и каталог вариантов показаны в контексте и отправляются вместе с выбранным текстом только по вашей кнопке. Это помогает избежать повторов и не заменить актуальный этап старым историческим событием. Точные совпадения названия/даты события или названия задачи помечаются как возможные дубликаты и по умолчанию не выбираются. Близкие по смыслу записи проверяйте вручную.

Выбранные изменения сохраняются одной транзакцией. Изменения полей фиксируются сегодняшним временем изменения в ChangeLog, а исторические события — собственными датами в Activity. Дата завершения импортированной выполненной задачи пока фиксируется временем добавления; для исторического завершения с точной датой сохраните соответствующее событие истории.

Для анализа нужен интернет. Учётные данные ChatGPT зашифрованы Electron safeStorage с системной защитой macOS и не передаются в интерфейс, SQLite или Git. История переписок в ChatGPT не запрашивается. Используется ваш план, без автоматического подключения платного API. Доступность и лимиты зависят от аккаунта. Основная работа без ИИ остаётся локальной.

Реальный ответ модели на личном аккаунте должен быть проверен пользователем; автоматические тесты используют только вымышленные данные и не расходуют лимиты.

- https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference

## Разработка

Нужен Node.js 24.15+ и npm. Весь исходный код локален и находится в Git.

```sh
npm ci
npm start
```

Браузерный запуск: http://127.0.0.1:3000, база `data/project-hub.sqlite`. Сервер слушает только `127.0.0.1`. Доступ к ChatGPT доступен только в Mac-приложении. `PORT=3001 npm start` меняет порт, `DB_PATH=/полный/путь/file.sqlite npm start` — базу.

```sh
npm run build
npm test
npm run desktop
npm run package:mac
```

`build` проверяет TypeScript и собирает интерфейс. `desktop` собирает и открывает Electron-версию. `package:mac` создаёт .app для архитектуры текущего Mac, используя официальный Electron. При первой установке runtime может потребоваться `node node_modules/electron/install.js` (если пакетный менеджер не запустил скачивание). При проблемах встроенного загрузчика можно скачать официальный ZIP, проверить SHA-256 по `node_modules/electron/checksums.json` и передать папку с файлом `electron-v<VERSION>-darwin-<ARCH>.zip` через `ELECTRON_ZIP_DIR` упаковщику. Уже готовая .app не скачивает runtime при запуске.

Для изменения иконки: `npm run icon` (macOS, Swift/AppKit, sips, iconutil). Готовые PNG/ICNS входят в Git.

## Структура

- `src/` — React, TypeScript, Tailwind, Radix Dialog, кнопка на шаблоне shadcn/ui, Lucide.
- `server/` — Express, SQLite, локальные API, атомарное сохранение предложений.
- `desktop/` — Electron, изолированный preload, OAuth ChatGPT, перенос базы.
- `shared/` — типы, проверка предложений, обработка потока Responses.
- `scripts/` — сборка, упаковка и иконка.
- `tests/` — API, сохранение после перезапуска, откат/повторы встречи, источники и дубликаты, поток, перенос базы.

Только четыре таблицы: Client, Task, Activity, ChangeLog. Версия схемы в PRAGMA user_version. Миграции должны сохранять данные. Задачи хранятся один раз. Последняя активность вычисляется из истории. Даты завершения и изменения полей сохраняются для будущих отчётов.

Отчёты, Excel и интерфейс резервного копирования — исходный этап 2, который требует отдельного согласования.

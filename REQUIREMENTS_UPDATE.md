# Уточнения требований — 16 октября 2026

Эти требования дополняют исходное ТЗ. Это согласованные цели, а не уже реализованные возможности.

## Запуск на Mac

Обычное приложение .app с иконкой, запуск двойным щелчком из Finder/Dock без Терминала и отдельной установки Node.js пользователем. Необходимые компоненты входят в поставку. Внутренние процессы запускаются автоматически и завершаются при полном выходе через Cmd+Q. Постоянно включённый сервер не нужен. SQLite хранится отдельно от пакета приложения, обновления и переустановка не должны удалять данные. Измерить потребление памяти и CPU на реальном запуске; пока никаких цифр не обещать. Конкретную оболочку выбрать при реализации.

## Визуальный стиль

Лаконичный дизайн в духе Apple: системная типографика, спокойные нейтральные поверхности, свободное пространство, тонкие разделители, сдержанные акценты и анимации. Понятные действия, минимум визуального шума. Сохранить русский язык, три раздела, удобные таблицы и светлую/тёмную темы. Не копировать интерфейс Apple буквально.

## Анализ расшифровки встречи

Опциональное подключение собственного ChatGPT пользователя. Сценарий: выбрать клиента → вставить/загрузить текст расшифровки → явно нажать «Проанализировать» → проверить предложения → выбрать и при необходимости отредактировать → сохранить выбранное.

Предложения: краткое содержание и запись встречи, решения и договорённости, задачи, ответственные и сроки (только если указаны), риски и изменения текущего состояния. Для предложений показывать опорный фрагмент расшифровки. Не выдумывать даты, ответственных или факты; неизвестные значения оставлять пустыми. Учитывать уже существующие задачи и показывать возможные дубликаты. Ничего не менять автоматически: сохранение только после выбора пользователя, с использованием существующих Client/Task/Activity/ChangeLog.

Отправлять в OpenAI только выбранную расшифровку и явно показанный необходимый контекст клиента по действию пользователя. Весь остальной функционал остаётся локальным и работает без ИИ/интернета. Учётные данные не помещать в Git и SQLite, для Mac использовать системное защищённое хранилище. Смена/отключение аккаунта не удаляет локальные данные. Текст расшифровки считать данными, а не инструкциями для доступа к приложению.

Технический способ подключения ещё не выбран и не реализован. Проверить применимость официального Sign in with ChatGPT к этому приложению, требования регистрации и доступность для пользователя. Не обещать использование подписки до проверки. API с отдельным биллингом — возможный запасной вариант только при явном выборе пользователя, без автоматического переключения.

## Разбор любой информации и свои варианты — согласовано пользователем

Разбор предназначен не только для встреч. Пользователь вставляет существующую сводку о клиенте, заметки, переписку или историю проекта. Приложение предлагает, когда и что происходило: несколько отдельных событий со своими датами, а также задачи и изменения текущих полей. Неизвестные даты не заменяются сегодняшней.

Этап — выпадающий список. Варианты этапов общие для всех клиентов (подтверждено пользователем). Пользователь сам задаёт этапы, типы клиентов, аналитиков, ответственных за задачи и типы записей. Эти же варианты используются в формах и предложениях ИИ. Произвольные новые поля в структуру клиента не добавляются. Состояния и статусы задач остаются фиксированными по смыслу для главной сводки.

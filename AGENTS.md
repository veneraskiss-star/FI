# Инструкции для разработчиков

Перед работой прочитать PROJECT_STATE.md, README.md, TASKS.md и REQUIREMENTS_UPDATE.md.
Не переписывать проект без необходимости. Сохранять простой локальный стек и русский интерфейс.
Не начинать этап 2 без явного согласования пользователя.
Не удалять и не пересоздавать пользовательскую базу. Использовать последовательные миграции с PRAGMA user_version, не теряя данные.
Не добавлять пользовательские базы, секреты или реальные клиентские данные в Git и тесты.
Сервер должен слушать только loopback. Не добавлять аналитику и телеметрию. Исключения для внешних вызовов: явно запускаемые пользователем анализ/отчёт через ChatGPT и согласованное подключение Яндекс 360 CalDAV для просмотра/создания встреч согласно REQUIREMENTS_UPDATE.md. Для Яндекс Почты согласованы IMAP-просмотр/поиск/вложения, флаги прочтения, SMTP-написание/ответы/пересылка только по явной кнопке и автообновление/IMAP IDLE с резервной проверкой раз в минуту, пока приложение открыто. Согласованы зашифрованное локальное хранение списка и открытых писем, системные уведомления о новых письмах и мягкий звуковой сигнал. Черновики локальные и зашифрованные. Реальные письма при разработке не отправлять; почту ИИ не передавать. Без скрытой отправки данных и иного фонового опроса. Календарные приглашения только выбранным пользователем участникам при явном создании встречи; запрос ссылки Телемоста согласован.
После значимых изменений обновлять PROJECT_STATE.md и TASKS.md; проверять npm run build и релевантные тесты.
Не дублировать задачи. Последнюю активность вычислять из истории. Сохранять изменения полей в ChangeLog.
